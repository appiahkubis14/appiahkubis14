## 🔬 Research Projects

<table>
<tr>
<td width="50%" valign="top">

### 🛣️ [MMFF](https://github.com/appiahkubis14/mmff) — Pothole Dimensioning

LiDAR-accurate pothole depth, width, and volume from a smartphone camera + IMU. No specialised hardware. Runs in real time.

**Results**
- Depth MAE: **0.28 m** &nbsp;·&nbsp; Width error: **6.2%**
- Throughput: **30 fps** on standard laptop CPU
- ETHHI reduces height error by **62%**
- MBTP reduces area error by **48.9%**

**Target:** *IEEE Transactions on Intelligent Transportation Systems*

`Python` · `TensorFlow` · `OpenCV` · `Kalman Filter` · `RANSAC`

</td>
<td width="50%" valign="top">

### 🌿 [Afarinsene](https://github.com/appiahkubis14/afarinsene) — Cocoa Disease AI

Production AI system for CSSVD detection from smartphone images. Deployed to 1,000+ farmers across Ghana and Côte d'Ivoire.

**Results**
- Test accuracy: **95.8%** &nbsp;·&nbsp; F1: **0.95**
- Cross-border accuracy: **91.5%** (Ghana → Côte d'Ivoire)
- Diagnosis time: **< 1 minute** vs 7–14 days traditional
- Formats: Keras · TFLite Float32 · INT8 Quantised

**Target:** *Computers and Electronics in Agriculture*

`Python` · `TensorFlow` · `Django` · `Celery` · `PostGIS`

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🌳 [Atewa-Watch](https://github.com/appiahkubis14/atewa-watch) — Mining Detection

Sentinel-1/2 + UAV fusion pipeline for detecting illegal mining (galamsey) in a 23,663 ha tropical forest reserve.

**Results**
- Recall: **82%** &nbsp;·&nbsp; Precision: **76%** &nbsp;·&nbsp; IoU: **0.61**
- Cloud-penetrating SAR restores recall from 0.41 → **0.78** in wet season
- Reduces UAV flight time by **80%**
- Interactive ranger dashboard (Folium)

**Target:** *Remote Sensing (MDPI) / IEEE JSTARS*

`Python` · `PyTorch` · `U-Net` · `YOLOv8` · `Sentinel Hub`

</td>
